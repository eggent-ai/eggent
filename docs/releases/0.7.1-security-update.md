# Eggent 0.7.1 - Security Update

Date: 2026-10-27  
Type: Patch release snapshot

## Release Name
`Security Update`

A security fix for the web server, and two small fixes. Update if you run
Eggent where anyone else can reach it.

## What Is Included

### 1) Security: Next.js 15.5.28, image optimizer off

- GHSA-2464-fhr4-w9xw: the image library behind Next.js's Image Optimization
  API (`/_next/image`) could run code on Linux with glibc, which is what the
  Docker image uses, without signing in. Next.js 15.5.26 pulled `sharp`
  0.35.4; 15.5.28 pulls the fixed 0.35.5.
- Nothing in Eggent uses `next/image`, so the optimizer is switched off as well
  (`images.unoptimized`): `/_next/image` converts nothing, and a later hole in
  the same place has nothing to reach.

### 2) A model's context window from the provider's own list

- A provider added by the agent (`eggent_manage_models add_provider`) now gives
  each model the context window its own `/models` endpoint reports
  (`context_length`, the smaller `top_provider.context_length`,
  `max_model_len`, `context_window`). A provider that reports only ids keeps the
  default of 128k. A provider added before keeps its old numbers until it is
  added again.

### 3) The usage meter after a change

- The meter in the sidebar asks for fresh numbers when a page opens or the tab
  comes back, instead of showing the previous figures for up to two minutes.

## Upgrade Notes

- Migration: none.
- Docker: pull `ghcr.io/eggent-ai/eggent:0.7.1` (or `latest`) and recreate the
  container. From source: `npm install`, then rebuild.
